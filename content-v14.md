# Cultzyme V14 — One Brain Across Every Scale

## Principio visual

El hero deja de representar una sonda o una lista de señales. La nueva visual es una **scale continuum** construida en SVG: small vessels, development, pilot e industrial aparecen como cuatro estaciones técnicas conectadas a un único brain. Cada estación alimenta al mismo modelo con process state y recibe decisiones de control desde él.

La animación avanza de izquierda a derecha. Un pulso de conocimiento viaja desde small vessels hasta industrial, activa cada escala y mantiene encendido el mismo brain. La lectura es inmediata:

> **SAME BRAIN → EVERY RUN → EVERY SCALE → SELF-DRIVING BIOPROCESS**

## Hero visual

La visual no reproduce marcas ni equipos comerciales. Utiliza siluetas lineales y escalas relativas: small vessels agrupados, reactor de desarrollo, sistema piloto y recipiente industrial. Una línea superior representa el brain y una línea inferior el control return. Los nodos de sensing aparecen como entradas pequeñas en cada escala.
