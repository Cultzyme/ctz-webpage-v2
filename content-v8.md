# Cultzyme V8 — Black Box → Glass Box

## Recomendación visual

La célula aislada se sustituye por un **biorreactor existente transformándose de Black Box a Glass Box**. La mitad izquierda aparece como un recipiente industrial oscuro y opaco, observado mediante pocos puntos de muestreo tardíos. La mitad derecha se vuelve transparente: revela el medio celular, sensores directos, una nube densa de observaciones, un estado predictivo y rutas de control que regresan al equipamiento.

Esta visual explica mejor que una célula qué hace Cultzyme. No reemplaza el biorreactor; instala una nueva capa de inteligencia dentro del proceso. También permite contar las tres partes del producto sin iconos genéricos: **observe → predict → act**.

## Hero annotations

La visual utiliza dos polos claramente rotulados. **BLACK BOX** contiene “SPARSE SAMPLES / LAGGING INDICATORS / OPERATOR DEPENDENT”. **GLASS BOX** contiene “DIRECT OBSERVATION / PREDICTIVE STATE / CLOSED-LOOP ACTION”. Entre ambos aparece una línea de transición con la fórmula **SENSORS → MODELS → PHYSICAL AI**.

## Cierre sin robot

El formulario se mantiene, pero el robot desaparece por completo. Su lugar lo ocupa una **control aperture**: un instrumento circular sobrio que representa el primer loop que Cultzyme puede mapear con el cliente. Al enfocar campos del formulario, el instrumento activa capas SENSE, MODEL y ACT; no tiene rostro, cuerpo ni personalidad de asistente.
