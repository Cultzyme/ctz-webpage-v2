# Canva V13 — Hallazgos técnicos

## Página 1 de 9

La presentación se titula **CULTZYME intelligent bioprocessing** y abre con la promesa **“Self-driving bioprocesses from lab to plant. Same quality, faster.”** Esta portada confirma la continuidad lab-to-plant y el outcome de calidad/velocidad, pero todavía no contiene el detalle técnico de la sonda.

El material se utilizará únicamente para validar claims y terminología de producto solicitados por el usuario. No se copiarán ni descompondrán layouts, recursos gráficos, Brand Kits o estructuras propietarias de Canva.

## Página 2 de 9

La presentación enmarca el problema en tres dimensiones: speed, data y economics. El claim más relevante para la web es **“Continuous extraction of data is critical”** y la idea de que la mayoría de señales del biorreactor no se capturan, por lo que cada run debería convertirse en training data en lugar de un resultado aislado. También utiliza como contexto el modelo tradicional de 20–30 runs, pero esta cifra no se incorporará públicamente sin validación adicional.

## Página 3 de 9

La arquitectura queda formulada como **Sensing + Modeling + Automation / One loop / Always under your control**. La misión se expresa como un operating system que lee el proceso, interpreta qué está haciendo y actúa sobre el equipamiento existente. Esta formulación respalda mantener el recorrido animado actual y sustituir el biorreactor del hero por una visual abstracta de señales que entran en un intelligence loop.

## Página 4 de 9

La formulación pública validada para Xcale es: **“A multiparametric sensor retrofits any bioreactor (from 250 mL to 20,000 L) and reads the process live.”** La analogía de plataforma es Eyes / Senses para Xcale, Brain / Reasons para Ereky y Hands / Acts para Omnix. El claim hero debe hablar de **one multiparametric sensing system**, no de sensores direct-analyte en plural.

## Página 5 de 9

El material diferencia dos formatos: **in-vessel chip para ambr® 250 y vasos menores**, y **multiparametric probe para stirred-tank bioreactors desde 1.5 L**. La capacidad de sensing se presenta como múltiples parámetros en un único dispositivo.

| Estado | Parámetros |
| --- | --- |
| Measured today | pH, dissolved O₂, CO₂, glucose, lactate, glutamine, glutamate, ammonia |
| In development | viable cell density, cell diameter, titer |
| Roadmap | electrolytes, osmolality, additional amino acids |

La web utilizará una formulación breve y prudente: **“One multiparametric probe. Multiple live process signals.”** El detalle completo de parámetros no se incluirá en el hero, pero puede aparecer como microtelemetría en la escena Xcale. La afirmación de retrofit se expresará como **“designed to retrofit existing bioreactor formats”**, evitando una garantía universal sin contexto técnico.

## Páginas 6–9

Ereky se presenta como **“the single brain across every run — live and historical”**. El usuario puede pedir análisis en lenguaje natural; el sistema devuelve reportes, forecasts, comparativas y recomendaciones auditables. También puede trabajar con señales históricas del cliente y construir soft sensors. Esto confirma que el hero no debe sugerir que toda medición depende de la sonda: Cultzyme puede comenzar tanto con Xcale como con datos existentes.

Omnix convierte la conclusión de Ereky en acción sobre el setup existente. La formulación autorizada contempla tanto self-drive programado como human-in-the-loop. La web mantendrá “approved actions” y “bounded, traceable Physical AI” para no presentar autonomía sin control.

El caso operativo del material utiliza una trayectoria de glucosa que cruza un límite operativo en 14 horas; el operador ajusta el feed rate y el batch se mantiene. Esta historia valida la estructura “See it before it becomes a failed run”, pero la landing conservará una versión agnóstica al parámetro para no limitar Xcale a un único caso.

La presentación también comunica prueba en una instalación R&D de una top-5 pharma y conversaciones de deployment con otros fabricantes. No se incorporará este claim en la revisión V13 porque el alcance solicitado es sensing y hero; puede utilizarse posteriormente como bloque de evidencia si Cultzyme confirma que debe publicarse.
